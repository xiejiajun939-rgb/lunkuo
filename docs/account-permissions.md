# 账号权限分组（2026-11-06）

## 展示方式

- 新版小店罗盘：每日明细、组织分析、商品分析（含抖店数据，当前联动）、推广参考。
- 快捷操作：全选新版普通页面、清空新版页面；不包含管理员专属访问统计。
- 旧版管理后台：系统设置、商品信息管理，仅管理员可用；不提供把普通账号提升为管理员的快捷勾选。
- 历史/其他站点兼容权限单独说明并保留，不伪装为新版菜单。
- 新建账号可以在创建前选择页面，默认为每日明细、组织分析、商品分析及其联动的抖店数据。
- 已有账号显示按当前选择及专属页面范围计算的新版页面预览，明确保存后才生效。

## 兼容与安全

不改前台权限接口、不改数据库结构、不自动更新任何真实账号。保存时使用旧版兼容权限值，保留其他站点历史授权及 `_ui` 等专属策略。已有空字符串范围和 `_all` 范围同步更新，避免撤销后旧范围恢复授权。

新版抖店数据当前在前台菜单及接口层都与商品分析权限绑定，因此不显示虚假的独立开关；专属 `pageAllowList` 仍可进一步限制页面。

## 验证

20项本地回归测试；Streamlit 1.66 实际组件测试覆盖初始显示、全选、模拟保存和策略保留。模拟数据库仅在内存中，不创建真实账号或更新真实权限。

线上发布标识：登录页 `data-account-permissions="grouped-v1"`。线上登录后权限操作应由管理员确认，不代替用户修改业务账号授权。
