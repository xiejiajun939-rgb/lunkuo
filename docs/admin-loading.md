# 管理后台按需加载优化（2026-11-06）

## 本轮修改

- 系统设置六个页签、商品信息管理四个页签启用状态跟踪，并只运行选中页签的代码。
- 登录前不预读全部账号。登录、恢复登录和管理员密码变更校验只查当前账号，密码撤销检查不使用长期缓存。
- 去掉后台入口自动加载店铺目标，以及登录成功时对所有数据缓存的无差别清空。
- 批量上传商品时，如未主动进行销售货号核对，不读取整个商品库；库存汇总只在查询维护页加载。
- 退差价模板、商品上传模板、商品库导出改为下载按钮点击后生成，避免每次渲染生成 Excel。
- 移除旧入口不再使用的图表及 AI 模块导入，降低冷启动开销。

## 保留与边界

- 上传控件及按钮 key、导入函数、管理员限制、销售货号核对按钮均保留。
- 切换页签会卸载不再显示的控件，提示用户先保存；未提交的编辑不保证跨页签保留。
- 商品查询/标签管理仍使用缓存的商品库做完整筛选与统计；本轮未改成数据库端分页，不声称消除了所有全量读取。
- 访问记录只在选中相应页签时读取；大时间范围仍可能需要后续分页。
- 不修改数据库结构、权限或密钥，不执行业务上传。

## 验证

- 13 项本地单元/结构回归测试覆盖隐藏页签不执行、单账号查询、去掉入口预加载、模板格式和认证安全。
- 独立 Streamlit 1.66 界面测试验证选中页签及文件上传/延迟下载控件可构建；测试不连接真实数据库。
- 发布标识：登录页的 `data-admin-loading="lazy-v1"`。
- 线上部署验证与真实账号操作验收分开报告，不用 HTTP 200 或本地测试代替真实上传成功。
