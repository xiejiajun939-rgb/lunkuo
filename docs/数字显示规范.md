# 数字显示规范

- 计算、筛选、排序和下载始终保留原始数值，不使用格式化文字参与计算。
- 金额、件均价和吊牌价使用千分位，保留 2 位小数。
- 件数、人数、场次和库存显示整数。
- 比例、占比、转化率和折扣率显示百分比，保留 2 位小数。
- ROI 显示倍数，保留 2 位小数，不加百分号。
- 缺失或无法计算显示 `—`；真实的零按对应类型显示为 `0`、`0.00` 或 `0.00%`。
- 金额为 0 的赠品不计件，也不参与件均价。
- 实销件数小于或等于 0 时，实销件均价显示 `—`。
- 日期统一显示为 `YYYY-MM-DD`，时间统一显示为 `YYYY-MM-DD HH:MM:SS`。
