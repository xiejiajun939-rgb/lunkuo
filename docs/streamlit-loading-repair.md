# 后台持续加载问题排查与修复

日期：2026-11-04。

## 已观察

- 原网址外层HTML和实际应用健康检查可返回200，但浏览器超过56秒仍无法进入登录页，尚未建立Streamlit WebSocket。
- 默认网络、直连及HTTP/1对照均复现，多个静态JavaScript请求长期等待；单个请求重试可能恢复，不能据此认定整站恢复。
- 这不是已证实的Supabase权限拒绝，未修改数据库权限或上传任何业务数据。

## 修复范围

将固定Streamlit版本从1.62.0更新到1.66.0，保留其他依赖约束、业务逻辑、原网址及登录配置。

隔离安装1.66.0运行原后台，约5秒出现登录表单，建立WebSocket，无前端JavaScript异常。该结果为本地验证，不代替线上验收。

线上应再次检查登录表单、WebSocket与管理入口；不要以首页HTTP200或Git推送成功代替应用可用。若新运行时出现不兼容，可将依赖固定版本恢复为1.62.0后重新构建；不得清库或放宽安全配置。
